# Gabarito ENEM 2026

App de estudos para o ENEM 2026, com foco em quem quer cursar Psicologia.

- 102 lições com o conteúdo das quatro áreas, aula em vídeo e a parte "Modo ENEM" (o que mais cai, passo a passo e pegadinhas).
- 422 questões com resolução comentada.
- Curso de redação, redação modelo comentada e editor com análise automática.
- Plano de estudos diário, simulados, prova completa e cartão-resposta das provas oficiais de 2023 e 2024 (gabarito oficial do INEP).
- Boletim com nota estimada por área, XP, níveis, conquistas e lembretes de estudo.

O progresso fica salvo no próprio aparelho (localStorage). É um site estático: basta abrir o `index.html` num servidor ou no GitHub Pages.
